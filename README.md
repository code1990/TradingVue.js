# TradingVue.js-Project

```bash
cd server
npm install
node index.js

cd client
npm install
npm run serve
```

## AI 项目上下文

- 用途：前后端分离的图表演示；前端在 `client/`，Node 服务在 `server/`。
- 入口：前端 `client/src/main.js` 与 `client/src/views/Chart.vue`，服务端 `server/index.js`。
- 修改原则：仓库包含已提交依赖目录；不要提交或更新 `node_modules`，只处理 `client/src`、`server` 和配置源码。
